# Claude Chrome拡張機能

[English](/README.md) | [日本語](/README.ja.md)

閲覧中のWebページや選択したテキストについて、ブラウザのサイドパネルでClaudeに質問・要約・翻訳できるChrome拡張機能です。

## 機能

- **サイドパネルで会話**: ページを操作しながら使え、パネルを閉じても会話は残ります（ブラウザを閉じるまで）
- **続けて質問できる会話形式**: 前のやり取りを踏まえて回答します
- **ワンクリック操作**: 要約・翻訳・解説・校正・返信案
- **右クリックメニュー**: 選択テキストやページ全体をそのままClaudeに送信
- **ページ全体の読み込み**: 選択しなくてもページ本文を添付して質問可能
- **読みやすい表示**: 見出し・箇条書き・表・コードブロック（コピーボタン付き）
- **ストリーミング表示と停止ボタン**、再生成、回答のコピー
- **モデル選択**: Claude Opus 5.5 / Sonnet 5.5 / Haiku 5.5
- **ライト／ダークモード**対応
- キーボードショートカット（初期設定: `Alt+Shift+C`）

## インストール方法

1. このリポジトリをクローン:
```bash
git clone https://github.com/ywsrock/claude-chrome-extension.git
```
2. Chromeで `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、`src` ディレクトリを選択

Chrome 116以降が必要です。

## 設定

1. サイドパネル右上の ⚙️、または拡張機能アイコンを右クリックして「オプション」を選択
2. [Claude Console](https://console.anthropic.com/settings/keys) で発行したAPIキーを入力し、「接続テスト」で確認
3. 必要に応じてモデル・思考の深さ・回答の言語・追加の指示を設定して保存

## 使い方

- **ツールバーのアイコン**（または `Alt+Shift+C`）でサイドパネルを開いて質問
- **✂️ 選択範囲** / **📄 ページ** で内容を添付してから質問
- **要約・翻訳など**のボタンを押すと、添付した内容（なければ選択範囲、それもなければページ全体）に対して実行
- 入力欄に文章を貼り付けてからボタンを押すと、その文章が対象になります
- ページ上で**右クリック**して「Claude AI Assistant」から操作を選ぶこともできます
- `Enter` で送信、`Shift+Enter` で改行（日本語入力の変換確定では送信されません）

## プロジェクト構造

```
src/
├── manifest.json     # 拡張機能の設定ファイル
├── background.js     # 右クリックメニューとサイドパネルの制御
├── sidepanel.html    # サイドパネルのUI
├── sidepanel.css     # サイドパネル・設定画面のスタイル
├── sidepanel.js      # 会話・ページ読み取り・表示
├── options.html      # 設定画面のUI
├── options.js        # 設定画面の処理
└── lib/
    ├── api.js        # Claude APIクライアント（ストリーミング）
    ├── markdown.js   # 応答の安全なMarkdown表示
    ├── page.js       # タブからのテキスト取得
    └── settings.js   # 設定値・モデル・クイックアクション・プロンプト
```

## 権限について

| 権限 | 用途 |
|---|---|
| `activeTab`, `scripting` | アイコンや右クリックで操作したタブの選択テキスト・本文の取得 |
| `sidePanel` | サイドパネルの表示 |
| `contextMenus` | 右クリックメニュー |
| `storage` | APIキー・設定・会話の保存 |
| `https://api.anthropic.com/*` | Claude APIへの送信 |
| すべてのサイト（任意） | アイコンを押さずに別のタブへ切り替えた後でページを読み取るときだけ、許可を求めます |

## セキュリティと注意事項

- APIキーはこの端末のブラウザ内（`chrome.storage.local`）にのみ保存され、Googleアカウントでは同期されません。v1で同期ストレージに保存されていたキーは、更新時に自動で移行・削除されます
- 添付したページの内容はAnthropicのAPIに送信されます。機密情報を含むページでは注意してください
- 長いページは先頭10万文字のみを送信します（画面に表示されます）
- `chrome://` ページやChromeウェブストアなど、拡張機能が読み取れないページがあります
